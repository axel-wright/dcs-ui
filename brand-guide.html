Display vs. Heading: When to Use Each

These two typefaces serve different roles. Inter carries the functional weight — navigation, labels, data. Playfair Display carries the emotional weight — it's the voice that stops someone scrolling.

"Tramming is the difference between a CNC that makes parts and a CNC that makes good parts."
High-contrast italic commands attention — reserved for moments that deserve it.
Rule of Thumb
  • Inter does the work. Navigation, data, buttons, forms — anything the user needs to act on or scan.
  • Playfair makes the statement. Hero titles, pull quotes, brand moments — anything meant to land emotionally or set tone.
  • Never swap them. A Playfair nav bar feels pretentious. An Inter pull quote feels sterile. Each has its place.
  • Together they create rhythm. A page that's all Inter feels clinical. All Playfair feels like a wedding invitation. The mix is the brand.

Extended Token Families

Beyond the core color, type, and spacing scales, DCS UI ships four supporting token families. They keep semantic intent, stacking order, and motion consistent across every component so you rarely need bespoke values.

Semantic Colors
--color-success / warning / error / info, each with matching -bg, -border, and -text variants for badges, tags, alerts, and validation.
Z-Index Scale
--z-base through --z-tooltip — a named stacking order so overlays, drawers, modals, and tooltips never fight for layering.
Motion
--duration-* and --ease-* drive every transition, keeping timing and easing curves uniform and easy to tune globally.
Utilities
A growing set of atomic helpers in utilities.css for spacing, flex, text, and visibility — reach for these before writing inline styles.

Print styles. DCS UI includes a print stylesheet (print.css) that forces the light theme, hides chrome such as navigation, toasts, and floating buttons, and expands collapsed content — accordions and tree groups — so a printed or PDF export reads as a clean, complete document.

05

Photography / Imagery

The photography language establishes an atmospheric, tactile connection. Below is the style blueprint and a live CSS/SVG visual direction.

  • Dark, dramatic lighting: High contrast, directional, single-source light setups. Let subject edges capture glows while background details recede.
  • Warm color temperatures: Emphasize deep gold, amber, and tungsten glows, avoiding cold neon or diagnostic white fluorescent lights.
  • Macro detail: Close-ups of steel blades, wood grains, dust particles, and material finishes.
  • Maker context: Focus on hands actively crafting. The creator is implied, the physical process is the focus.
  • Atmospheric motion: Stutter sparks, dust floating, lathe turn speeds, using slight motion blur to indicate authenticity.
  • Never use: Sterile white-background product sheets, cool blue tones, generic stock corporate photography.

Monochrome Hero Image Treatment

For article headers, landing pages, and section heroes — full-bleed photography is desaturated, sepia-tinted to the brand palette, and dimmed or lifted to match the active theme. The result: atmospheric, on-brand imagery that never fights the text.

Dark Mode
Deep, atmospheric — the image recedes into shadow
filter: grayscale(100%) sepia(35%) brightness(0.35);
Light Mode
Washed, airy — cream background bleeds through
filter: grayscale(100%) sepia(55%) brightness(1.15);
opacity: 0.40;
Implementation Notes
  • The image sits absolutely positioned behind an overlay gradient that fades to var(--bg-default) — no hard edge, just a smooth dissolve into the page background.
  • Dark mode uses brightness(0.35) for a deep, moody near-silhouette — the title and badge pop forward.
  • Light mode combines sepia(55%) with opacity(0.40) — the cream #f5f2eb background bleeds through, naturally washing the image without artificial filter gymnastics.
  • Hero height: 640px (desktop), 480px (mobile). Content padding: var(--space-3xl) (64px).
  • Title: Playfair Display italic 64px, centered, with subtle text-shadow for legibility over the image.
